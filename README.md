# EvolveYD.Blog

> 个人技术博客 — 记录从 0 到 1 的 Web 开发之旅
>
> **在线访问：[https://evolveyd.top](https://evolveyd.top)**

## 技术栈

- **框架**: Next.js 16 (App Router)
- **语言**: TypeScript
- **样式**: Tailwind CSS v4
- **内容**: Markdown + gray-matter + remark + rehype-pretty-code
- **部署**: Vercel

## 功能

- Markdown 博客系统（代码高亮、标签、阅读时间）
- 暗黑模式切换
- 全文搜索
- TOC 目录导航
- RSS 订阅 (`/feed.xml`)
- Giscus 评论系统
- SEO 优化（sitemap、robots.txt、JSON-LD、Open Graph）

## 本地运行

```bash
npm install
npm run dev
```

打开 http://localhost:3000
